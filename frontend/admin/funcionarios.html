Funcionários / Dependentes

Crie o acesso dos seus funcionários e controle a cota do seu plano.

Como funciona

Crie um login (e-mail) e uma senha para cada funcionário aqui, ou o próprio funcionário pode criar a conta pela opção Funcionário / Dependente do /login e vincular à empresa informando o Código Único (o código aparece no painel Início). O funcionário acessa a agenda e os clientes da empresa — os relatórios financeiros/gerenciais ficam bloqueados para esse perfil. Use Desligar para remover o vínculo (a conta continua existindo); use Remover para apagar a conta em definitivo.
